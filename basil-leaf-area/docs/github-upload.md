# Загрузка на GitHub

Предлагаемое имя репозитория: `basil-leaf-area`.

Описание: `Computer vision for basil leaf projected area: fixed-distance segmentation and a distance-compensation experiment with a cube tower.`

Темы: `computer-vision`, `instance-segmentation`, `yolo`, `opencv`, `plant-phenotyping`, `basil`, `esp8266`.

1. Создайте репозиторий в своём аккаунте.
2. Распакуйте ZIP. Загрузите содержимое папки `basil-leaf-area` в корень репозитория: `README.md` должен оказаться сразу в корне.
3. Если загружаете через браузер, включите `.gitignore`: некоторые файловые менеджеры скрывают файлы с точкой.
4. Веса и полные датасеты не включены. Для запуска добавьте два checkpoint локально согласно `weights/README.md`. При последующей публикации весов можно использовать GitHub Releases.

В архиве нет вложенных Git-репозиториев, исходной копии CVAT, полного датасета и pretrained-весов. Выбор лицензии и добавление библиографических ссылок на опубликованные тезисы остаются за автором.
